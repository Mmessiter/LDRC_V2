# keybdA (page 56): the full keyboard. A box whose key is 1 opens it after its own touch event has set the question
# (keybdA.t1.txt=...); the screen sets loadpageid / loadcmpid (src/main.cpp openKeyboard) and the keyboard's
# preinitialize copies the caller's text into input (txt_maxl: how many letters it takes). Callers: RenameView NewName
# "Model name" (30), BackupView t1 "File name" (20), OptionsView TxName "Owner's name" (30), InputsView ch1-16
# "Name for Channel n" (10). A finger is "click NAME,1" / "click NAME,0" (that part's press / release event): the box's own event
# sets the question, as on the transmitter; the screen's part (loadpageid, loadcmpid, the page) is written out.
Screen_Background=8

keybdA.loadpageid.val=50
keybdA.loadcmpid.val=2
page keybdA

page RenameView
