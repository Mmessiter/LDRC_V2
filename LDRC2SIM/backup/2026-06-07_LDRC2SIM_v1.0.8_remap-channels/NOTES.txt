LDRC2SIM — v1.0.8, CONFIRMED WORKING (2026-06-07). Adds user channel remapping.
Builds on v1.0.6 (USB HID joystick, auto-detect CRSF/SBUS/IBUS/PPM on D7,
failsafe-hold, WiFi AP/STA portal, mDNS, web OTA).

NEW — "Remap channels" feature (front-screen button):
- Page lets the user feed any of the 8 USB outputs from any of the 16 RX input
  channels, with a per-output reverse tick. Saved to NVS (survives reboots),
  takes effect immediately.
- Three-layer mapping so the default looks simple yet flies like RX2SIM:
    LOGICAL channel (what the user/neXt see: 1=ail,2=ele,3=rud,4=thr,5..8=aux)
    BASELINE (hidden, baked in: BASE_MAP={0,1,3,2,4,5,6,7}, BASE_REV rudder=true;
              folds in throttle/rudder swap + rudder reverse + neXt rotation)
    USER MAP (editable; defaults to identity 1:1, no reverses = "unmapped")
  fillAxes: out=(k+8-MAP_ROT)%8; L=userMap[out]; phys=BASE_MAP[L];
            rev=BASE_REV[L]^userRev[out]. Default reproduces the proven
            {6,7,0,1,3,2,4,5} report exactly.
- Per the user's request the default reads as a tidy Out N -> Ch N with no
  reverses ("unmapped"), even though the baseline still does the RX2SIM work.

Plumbing:

- web_portal.cpp externs userMap[8]/userRev[8] from main.cpp; loadMap()/saveMap()

Unchanged essentials:

- Local firmware server: python3 dev/firmware_server.py (port 8001). dev/ holds
  LDRC2SIM-1.0.0..1.0.8 release bins.
- USB: VID 0x1209 / PID 0x525C / serial LDRC-P1-0005.
- LDRC2SIM_firmware.bin = the exact 1.0.8 image.
