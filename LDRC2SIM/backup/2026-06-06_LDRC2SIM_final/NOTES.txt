LDRC2SIM — FINAL working version (2026-06-06), verified FLYING in neXt.
- XIAO ESP32-S3, native USB HID joystick, 8 axes (16-bit), Report ID 1,
  axes inside a Physical collection.
- Auto-detect RC: CRSF / SBUS / IBUS / PPM on pin D7 (GPIO44).
- USB: VID 0x1209 / PID 0x525C, manufacturer "LDRC", product "LDRC2SIM",
  serial "LDRC-P1-0005".
- SBUS channel map AXIS_SOURCE = {6,7,0,1,3,2,4,5}; rudder reversed.
  -> neXt order matches RX2SIM: aileron=0, elevator=1, rudder=2, throttle=3.
- 1 Hz CDC heartbeat. Sine self-test when no RC link.
- LDRC2SIM_firmware.bin = exact flashed binary (esptool write at 0x10000).
