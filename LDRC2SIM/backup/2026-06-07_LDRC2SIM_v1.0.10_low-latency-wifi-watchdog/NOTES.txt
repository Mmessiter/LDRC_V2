LDRC2SIM — v1.0.10, CONFIRMED WORKING (2026-06-07). Low-latency reporting +
robust Wi-Fi reconnect. Builds on v1.0.8 (Remap channels feature, bars UI).

LATENCY (user reported motor on/off now "very quick"):
- HID reporting is now EVENT-DRIVEN: a report is sent the instant a fresh RC
  frame is decoded, instead of on a fixed 333 Hz timer. RX->USB latency drops
  from up to ~3 ms to roughly the loop spin time (sub-ms).
    MIN_SEND_US  = 1000  -> 1 kHz cap (matches USB full-speed HID bInterval=1ms,
                           which the arduino-esp32 core already sets; verified).
    HEARTBEAT_HZ = 200   -> keep-alive resend when no new frame (failsafe-hold).
  RcInput::update() now returns bool (true on a new frame) to drive this.
- Web /status poll capped to ~60 Hz (was "as fast as round-trip"): an open
  Channels/Remap page could starve the single-threaded loop and the RC->USB
  path. 60 Hz is plenty (bars smooth client-side).
- UART RX buffer 512 -> 1024 (~24 ms headroom at CRSF 420 kbaud).
- Heartbeat now prints worstGap=<us> (largest send-to-send gap each second) for
  measuring stalls.
- NOTE: a slight lag on the *very first* motor switch-on remains; believed to be
  the simulator's model spool-up, not the firmware.

WI-FI RECONNECT (fixes recurring "reverted to AP mode"):
- Real cause: device runs WIFI_AP_STA so the AP is always up; the STA (home)
  side was dropping and never retrying. setAutoReconnect alone gives up after
  some disconnect reasons / a router blip, and nothing in loop() retried.
- Fix 1: reconnect watchdog in WebPortal::loop() — every STA_RETRY_MS (10 s),
  if creds are set and WiFi.status()!=WL_CONNECTED, re-issue WiFi.begin()
  (non-blocking, never stalls the flight path).
- Fix 2: mDNS restarted on every STA GOT_IP (WiFi.onEvent). It was started once
  at boot before the STA had an IP, so it only answered on the AP iface; now
  LDRC2SIM.local resolves on the LAN after any (re)connect. Verified: dns-sd
  resolves LDRC2SIM.local, _http._tcp advertises "LDRC2SIM", ping ~2 ms.
- Fix 3: WebPortal::homeWifi() (-1 none / 0 down / 1 up) shown in the heartbeat
  as wifi=none/DOWN/up.
- Verified: after the OTA reboot the device auto-rejoined home WiFi unaided.

Unchanged essentials:
- WiFi.setSleep(false). Asset cache-bust tied to FW_VERSION. Three-layer channel
  map (logical -> hidden RX2SIM baseline -> editable user map, default 1:1).
- Public messiter.com update source still DISABLED (FW_PUBLIC_MANIFEST="").
- Local firmware server: python3 dev/firmware_server.py (port 8001). dev/ holds
  LDRC2SIM-1.0.0..1.0.10 release bins.
- USB: VID 0x1209 / PID 0x525C / serial LDRC-P1-0005.
- LDRC2SIM_firmware.bin = the exact 1.0.10 image.
