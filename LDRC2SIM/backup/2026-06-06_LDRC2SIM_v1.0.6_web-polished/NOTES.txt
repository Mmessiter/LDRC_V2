LDRC2SIM — v1.0.6, CONFIRMED WORKING (2026-06-06, evening).
Full product: USB HID joystick (8 ch, RX2SIM order, rudder reversed) + auto-detect
CRSF/SBUS/IBUS/PPM on D7 + failsafe-hold + WiFi AP/STA portal + mDNS + web OTA.

Web UI (house style): Home (TX detected/ not), Channels (60fps smoothed bars),
Wi-Fi (async scan, 2.4GHz only, show-password), Protocols/Help (auto-detect, no
protocol selection; 3-pin wiring), Firmware (version list from local server:
install/rollback/reinstall, OTA pull).

Notes:
- WiFi.setSleep(false) -> ~3ms latency (smooth + snappy).
- Asset cache-bust tied to FW_VERSION.
- Public messiter.com update source DISABLED (FW_PUBLIC_MANIFEST="") to avoid a
  blocking TLS hang; re-enable when the site is live.
- Local firmware server: python3 dev/firmware_server.py (port 8001). dev/ holds
  LDRC2SIM-1.0.0..1.0.6 release bins.
- USB: VID 0x1209 / PID 0x525C / serial LDRC-P1-0005.
- LDRC2SIM_firmware.bin = the exact 1.0.6 image.
