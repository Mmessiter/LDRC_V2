# TXV3: a transmitter with boards of its own (parked)

Notes, shopping lists and KiCad files for a future LockDownRadioControl transmitter
designed from scratch: its own main board with an ESP32 and a USB-C charger, new
gimbals and switches, a new case. The Rev-A and Rev-B boards were made and partly
assembled in 2026.

**It is parked.** Version 2, the Version 1 transmitter with the new 5-inch screen
(`../TXV2`, `../TXV2-Screen`), turned out so well that the motivation to move on may
prove insufficient for a long time. Everything here is kept for the day it is wanted.
The folder was called TXV2 until October 2026, when Version 2 became the name of the
transmitter that flies; some notes inside still say TXV2 of this design.
