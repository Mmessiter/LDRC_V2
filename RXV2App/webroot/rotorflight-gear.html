Gear ratio

so the governor and the transmitter know the true head speed

Enter the teeth counts: motor pinion (or pulley) : main gear (or pulley). Rotorflight turns motor RPM into head speed with this — the governor holds that number and the transmitter shows it. Belt + gear two-stage drive (SAB Goblin, RAW, Black Thunder): multiply the stages — motor pulley × drive pinion : big pulley × main gear (Goblin 770 = 21×19 : 60×68 = 399 : 4080; tail = tail pulley × pinion : front tail pulley × main gear = 25×19 : 37×68 = 475 : 2516).
