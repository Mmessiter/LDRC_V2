See and delete the transmitter's log files.||
Touch a file, then press 'View' to read it, or 'Delete' to|
remove it (you are asked first).|
'OK' goes back to the log viewer.||
Each file is one day's log, named by its date: day, month, year.|
So 01-10-26.LOG is 1 October 2026. Its size in KB is beside it.|
Below the list: the card's total size, the space used and free.||
Only one file is made each day. Each event in it is marked with|
the time from the transmitter's clock. If the clock cannot be|
read, the file is called NO_CLOCK.LOG.||
In a log, drag the text up or down to scroll.|
'Top' and 'Bottom' jump to the start and the end.||
When there are more than 90 log files at switch-on, the oldest|
are deleted, leaving the newest 80.||
What is logged is set on 'Transmitter setup', 'System', then|
'Next >' twice (Advanced).||
Opened from a help page, this list shows the help files instead:|
'View' reads one. Help files cannot be deleted.|
