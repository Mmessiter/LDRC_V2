It is kept for reference. It describes the gyro settings (PIDs,|
a Kalman filter, an MPU6050 sensor) of an earlier LDRC design.||
PID SETTINGS (THEY SET HOW THE MODEL RESPONDS):|
PID_P - Proportional gain.|
- Too low: the response feels sluggish.|
- Too high: the model may oscillate.|
PID_I - Integral gain.|
- Helps correct a steady drift or imbalance.|
- Increase it slightly if the model tends to lean|
or drift one way.|
PID_D - Derivative gain.|
- Smooths rapid movements.|
- Increase it to calm fast corrections. Reduce it if the|
response feels delayed.||
KALMAN FILTER:|
Kalman on: turns on the Kalman filter.|
Q_angle - Trust in the accelerometer's angle.|
- Higher: trust the accelerometer more. Lower: trust|
the gyro more.|
- If the angle drifts slowly over time, increase it. If it|
is jittery, reduce it.|
Q_bias - Trust in the gyro's drift estimate.|
- Sets how quickly the gyro's bias is corrected.|
- If the model slowly veers off over time, increase it. If it is|
noisy or jumpy, reduce it.|
R_measure - Trust in the accelerometer's measurement.|
- Higher: assume more sensor noise. Lower: rely more on|
the accelerometer.|
- If the angle is noisy, increase it. If it is slow to|
level, reduce it.||
SMOOTHING:|
alpha - Smooths the angle measurements.|
- 0.00 is no smoothing, 1.00 is very slow changes.|
- Raise it if the pitch and roll angles look jittery.|
beta - Smooths the gyro rates (the rate-of-rotation data).|
- Increase it if the model overreacts to small|
inputs or to noise.|
LPF - Low-pass filter on or off.|
- Turns extra rate filtering on or off.|
- Useful for helicopters, to tame aggressive behaviour.||
CALIBRATION:|
Calibrate MPU6050 now! - starts the sensor calibration.|
- Place the model still and exactly level.|
- Do not move it during calibration.|
