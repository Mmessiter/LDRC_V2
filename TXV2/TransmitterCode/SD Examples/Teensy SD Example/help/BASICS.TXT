The model's basics: what kind of helicopter the flight|
controller is flying, and how it talks to the ESC.|
The phone app calls these 'First-time basics'; in the|
configurator they are on the Mixer and Motor tabs.||
Set them once, when a model is new. The Mixer pages show|
the first three but do not change them.||
Tap a choice to step to the next one; tap a number to type.|
'Save' appears once something is changed. It writes all the|
Model basics pages, stores them, then RESTARTS the flight|
controller (these take effect when it starts) and reads them|
back:|
allow a few seconds. It asks first.|
'Next >' goes on to the gear ratios, then the ports, then the|
ESC throttle calibration, changes kept.|
'OK' leaves; if a change was not saved, it asks first.||
Swash type: None, Direct, CCPM 120, 135 or 140 degrees,|
FPM 90 L or V. The configurator's Swashplate type.|
Rotor turns: Clockwise or Anticlockwise, seen from above.|
The configurator's Main rotor direction.|
Tail type: Variable pitch, Motorised or Bi-directional.|
The configurator's Tail rotor type.|
ESC signal: how the throttle is SENT, not the brand.|
Helicopter ESCs (Scorpion, Kontronik, YGE, Hobbywing) use|
PWM; DShot is for drone-style ESCs. Off disables the motor.|
ESC brand: the telemetry language on the ESC's telemetry|
wire (Scorpion, Kontronik, Hobbywing V4 or V5, OpenYGE ...).|
None if no telemetry wire is connected. '?' means this|
flight controller has no ESC telemetry.|
Motor pole count: the magnets in the motor bell (2 to 64,|
an even number). Count them or read the motor's sheet.|
The flight controller needs it to turn electrical RPM into|
true motor RPM.||
With no model, the pages show and edit the model's backup on|
the card; the changes go to the model when it next connects.|
Nothing restarts then.|
