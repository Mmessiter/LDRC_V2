# The Version 2 transmitter case

The case as built on 10 October 2026. Print it in PETG or PLA. A newer version may follow: check the repository before printing.

| File | What it is |
|---|---|
| `TXV12a_Front_V2.step` | The front: holds the 5-inch CrowPanel screen, the gimbals, the switches and the trims. |
| `TX_BACK12a_V2.step` | The back. |
| `CHARGERBAY.stl` | The bay for the small USB-C 2S charger module, with a window for its charge LED. |

Most slicers (PrusaSlicer, Bambu Studio, OrcaSlicer, Cura with its STEP plugin) open STEP files directly.
The other parts (handle, supports, gimbal protector, antenna parts) are the Version 1 parts in the folders above.

How to build the whole transmitter: https://messiter.com/ldrc/build.html
